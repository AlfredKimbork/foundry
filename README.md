# Foundry

Foundry is a custom WordPress theme created as a school project.

The goal of the project is to create a simple and customizable WordPress theme that can be adapted for different types of websites.

## Built With

- WordPress
- PHP
- Tailwind CSS
- JavaScript

## Features

- Responsive design
- Custom header and footer
- Mobile navigation
- Site search
- Customizable theme colors
- Footer widgets
- Customizable CTA
- Gutenberg support
- Archive and search layouts
